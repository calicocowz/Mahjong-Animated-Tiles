LINES TILES

Animated mahjong tiles in the style of Lines, in five sets. Road is the race on a tile; Sheet is the Lines editor in ink; Garden is a flower bed for every number; Flair is neon on a dark tile; Block is the 3D view. Every tile is live SVG drawn by one small script: no images, no dependencies, and the motion is plain CSS.

Write a hand

Type a hand in the usual notation: digits, then their suit (m characters, p dots, s bamboo, z honours). 0 is a red five; a space leaves a gap.

At the table

Click a tile to discard it. The river fills the way it does in a real hand.

The full sets
Use it on a website

Put lines-tiles.js next to your page (or load it from a CDN, below), then write a tag per tile or per hand.

<script src="lines-tiles.js"></script>

<lines-tile set="flair" tile="5p"></lines-tile>
<lines-hand set="sheet" tiles="123m 406p 789s 11z"></lines-hand>

<script>
  // or build the markup yourself
  el.innerHTML = LinesTiles.svg("flair", "7z", { size: 48 });
  el.innerHTML = LinesTiles.hand("sheet", "123m406p", { size: 36 });
</script>
  • set: road, sheet, garden, flair or block.
  • tile: 1m to 9m, 1p to 9p, 1s to 9s, red fives 0m 0p 0s, honours 1z to 7z (East, South, West, North, White, Green, Red), and back.
  • size is the tile width in pixels (default 48). motion is on, hover or off; a visitor who asks their system for reduced motion always gets still tiles.
  • Screen readers hear each tile's name ("red 5 pin", "East"), and a whole hand as one list.
